# Agent_O 专属知识库使用说明

本知识库专为 Agent_O 珠宝门店智能培训与经营辅助系统生成，适合导入 Dify 知识库后供当前系统页面与工作流检索：

- 在岗助手：产品知识、销售话术、异议处理、合规红线
- 智能陪练：陪练场景、销售话术、异议处理、复盘评分
- 考试中心：动态考核、标准试卷、评分标准、合规边界
- 我的成长计划：14天成长路径、个性化训练、复盘与能力更新
- 风险看板 / 一句话查询：指标口径、日报周报、库存分析、复购跟进
- 答辩演示：系统定位、Dify 工作流、3 分钟演示口径

导入建议：
1. 不要导入旧版 “- 副本” 文件，本目录已去重。
2. Dify 分段建议使用自动模式；如需更稳定检索，可按类别拆成多个数据集。
3. 合规和售后类文档正式上线前需结合门店实际制度再次复核。
4. 检索测试建议使用“顾客担心买到假货”“首饰变色投诉”“婚嫁三金怎么推荐”“转化率下降怎么分析”等业务问题。

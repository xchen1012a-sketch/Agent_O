# 【异议处理】顾客说等促销再买的应对

## 元数据
- 系统：Agent_O 珠宝门店智能培训与经营辅助系统
- 推荐数据集：Agent_O综合知识库
- 适用模块：在岗助手 / 智能陪练 / 考试中心
- 检索关键词：等促销、活动、犹豫、跟进
- 文档定位：系统专属业务知识，不作为法律、医学、投资或鉴定结论；正式上线前需结合门店制度复核。

## 使用目的
用于顾客把购买决策延后到未来活动时的处理。

## 标准知识要点
- 等促销可能是价格顾虑，也可能是不确定是否喜欢。
- 不能虚构活动，也不能承诺未发布优惠。
- 应帮助顾客确认款式是否合适，再根据真实活动规则跟进。

## 标准执行动作
- 先认可：“等活动比较一下也正常。”
- 再确认：“您主要是想等价格，还是还没确定款式？”
- 最后跟进：“我先帮您记录这款参数和尺寸，后续有符合规则的活动再按门店政策提醒您。”

## 智能体回答边界
- 不得编造未来活动。
- 不得承诺超出权限的保价或折扣。

## 场景问答素材
- 顾客：我等促销再买。 员工：可以的，我先帮您确认是不是这款最合适，如果款式确定，后面比较活动会更清楚。
- 顾客：以后会不会更便宜？ 员工：活动以门店公示为准，我不能提前承诺，但可以帮您记录关注款。

## 评分与复盘关注点
- 是否先承接顾客情绪，再识别真实顾虑。
- 是否给出事实依据和门店流程，而不是只靠安慰或催促。
- 是否避免虚假承诺、贬低竞品、绝对化和隐私越界。
- 是否形成可执行下一步，例如试戴对比、登记检测、约定反馈或复看跟进。

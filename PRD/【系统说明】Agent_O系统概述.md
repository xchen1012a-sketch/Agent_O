# Agent_O 系统概述

## 1. 系统简介

Agent_O 是一套面向珠宝门店的智能培训与经营辅助系统。它把门店知识库、智能陪练、考试中心、成长计划、经营分析、Agent 协同编排和自我进化机制整合到同一套前后端系统里，核心目标是帮助门店把“知识、训练、评估、经营”串成闭环。

系统不是单纯的聊天机器人，而是一个可检索、可训练、可评分、可复盘、可管理的业务平台。

## 2. 系统定位与业务边界

- 面向珠宝门店销售培训、在岗支持、考试评估和经营辅助。
- 主要服务对象为管理员、店长、资深顾问、导购。
- 重点解决新人培养周期长、话术不统一、复盘不标准、经营数据难转成行动建议等问题。
- 系统只做培训、服务、复盘和经营分析辅助，不替代鉴定机构、法律裁决或人事决策。

## 3. 角色体系

### 3.1 管理员

- 管理人员、门店、知识库、培训任务和系统配置。
- 查看审计记录、系统日志、数字人设置和治理配置。

### 3.2 店长

- 查看风险看板、经营概览和一句话查询结果。
- 安排训练、跟进团队表现、分配任务、查看门店经营问题。

### 3.3 资深顾问

- 重点使用在岗助手、理论学习、智能陪练、考试中心和成长计划。
- 承担门店知识传帮带和实战辅导。

### 3.4 导购

- 重点使用理论学习、智能陪练、考试中心、在岗助手和我的成长计划。
- 通过任务、练习、评估和复盘逐步完成上岗成长。

## 4. 总体架构

- 前端是单页应用，基于左侧导航切换各业务页。
- 后端是 FastAPI 服务，统一承载登录、人员、知识库、训练、考核、分析和治理接口。
- 数据层以 SQLite 为主，同时结合 ORM、审计表、训练记录和知识库文档表。
- 智能层由 Dify 工作流与知识库检索共同驱动，覆盖陪练、问答、考核、成长、查询和自我进化。
- 语音层提供 TTS 和数字人能力，用于在岗助手、知识问答和演示场景。
- 治理层包含权限控制、登录锁定、限流、审计日志、环境配置和健康检查。

## 5. 全部功能模块

### 5.1 首页与统一导航

- 提供系统入口、模块切换和角色视图。
- 页面覆盖学习训练、考核复盘、成长规划、业务助手、组织管理、培训运营和系统治理。
- 支持移动端与桌面端适配。

### 5.2 登录认证、账号资料与权限控制

- 用户登录、Token 鉴权和当前用户信息获取。
- 个人资料修改，包括昵称、手机号和密码修改。
- 首次登录识别、登录失败锁定、账号安全控制。
- 按角色限制功能可见范围，避免普通用户接触高风险管理操作。

### 5.3 人员管理与门店管理

- 管理用户、门店、角色和员工基础档案。
- 支持员工列表、门店列表、用户创建、编辑、删除和角色分配。
- 支持员工成长轨迹查看，关联训练、陪练、考试和能力变化。

### 5.4 理论学习中心

- 上传、发布、下架、删除理论学习文档。
- 浏览已发布学习资料，查看文档详情与附件。
- 为新人和导购提供先学后练的基础知识输入。
- 内容通常包括产品知识、销售话术、异议处理、合规规范和门店制度。

### 5.5 知识库管理

- 管理知识库数据集、文档、文本导入和分段索引。
- 支持知识库创建、删除、文档上传、纯文本录入、段落查看和检索测试。
- 支持知识库与工作流映射，方便不同业务模块调用对应知识。
- 是整个系统的内容底座，决定回答、陪练、考核和分析的知识来源。

### 5.6 在岗助手

- 面向门店真实接待场景的即时辅助。
- 主要处理产品知识、销售话术、异议处理、合规表达和顾客应对建议。
- 支持自然回复和对话模式，适合边接待边查询。
- 可结合语音能力，形成更贴近门店现场的支持方式。

### 5.7 知识问答

- 面向门店知识检索型问答。
- 可回答珠宝产品、销售话术、售后边界、合规红线等问题。
- 支持知识检索后生成结构化回复，避免只给碎片化答案。
- 适合新人自学、店长查标准、顾问查话术。

### 5.8 一句话查询与经营分析

- 支持把自然语言问题转成可执行查询或分析结果。
- 覆盖门店经营指标、销售日报与周报、库存畅滞销、顾客画像、复购跟进、排班协同等主题。
- 支持“解析”和“总结”两段式处理，先识别问题类型，再生成经营建议。
- 适合店长和管理员做快速经营判断。

### 5.9 智能陪练

- 通过模拟顾客对话，训练顾问接待、挖需、推荐、异议处理和收口成交能力。
- 支持陪练场景、逐轮反馈、导师金句、结果评估和能力更新。
- 能把练习过程沉淀为可复盘记录，而不是只留下聊天记录。
- 适合新人训练、老员工补短板和门店统一话术。

### 5.10 考试中心

- 支持动态考核对话、标准试卷生成、标准试卷阅卷和阶段晋级解锁。
- 支持考试任务发布、考试任务列表、我的待办和历史记录。
- 用于验证员工对产品知识、销售话术、合规边界和门店制度的掌握程度。
- 兼顾客观题与场景题，强调“会说”也强调“会做”。

### 5.11 复盘本与错题本

- 记录陪练、考试和学习中的薄弱点。
- 支持错题标记、掌握标记、汇总查看和复盘追踪。
- 让训练结果可回看、可清理、可再练，形成闭环。

### 5.12 我的成长计划与成长之旅

- 生成个性化成长计划，匹配 14 天成长路径和阶段任务。
- 根据训练、考试和复盘结果更新学习计划和能力画像。
- 展示员工成长轨迹，串联学习、陪练、考试、任务和能力变化。
- 适合新员工入职成长、阶段晋升和能力补弱。

### 5.13 培训任务与训练周期

- 支持培训任务创建、发布、归档、重做、删除和我的任务查看。
- 支持训练周期进度、每日任务、阶段切换、完成确认和阶段复审。
- 支持新员工入职引导、首阶段任务下发和晋级解锁。
- 这是把“训练计划”真正落到日常执行的调度层。

### 5.14 经营看板与风险看板

- 提供门店经营概览、风险提示和重点指标查看。
- 支持销售、客流、库存、复购、人员协同等运营视角。
- 可辅助识别高峰排班压力、库存压力、转化波动和复购跟进问题。
- 更适合店长和管理者做决策，不是简单数据展示页。

### 5.15 Agent 协同编排

- 把系统拆成多个职责明确的智能体角色。
- 前端可视化展示 Agent 拓扑，后端同步活动流和调用记录。
- 支持查看“哪个 Agent 正在调用哪条工作流”，方便演示和排障。
- 让问答、陪练、考核、分析和自我进化形成分工协作。

### 5.16 EVO 记忆与自我进化

- 包括语义记忆抽取、反思经验生成和技能规则综合。
- 支持记忆治理、复核队列、回滚、晋级、评测和异常扫描。
- 用于把真实对话、复盘经验和规则沉淀成可复用能力。
- 让系统从“回答问题”逐步走向“积累经验”。

### 5.17 系统治理与审计

- 提供系统日志、审查记录、健康检查和治理页面。
- 支持环境配置上传与动态同步，便于部署和维护。
- 包含登录风控、请求限流、异常兜底和审计追踪。
- 保证系统可控、可查、可运维。

### 5.18 数字人与语音能力

- 支持语音合成和流式语音输出。
- 支持数字人系统设置与偏好配置。
- 可用于在岗助手、知识问答、演示讲解和数字人接待场景。

### 5.19 演示与答辩支持

- 系统内置 3 分钟演示讲解口径。
- 演示时可串联知识库、智能陪练、考试中心、成长计划和风险分析。
- 适合作为项目答辩、培训展示和业务汇报材料。

## 6. Dify 工作流与智能体映射

### 6.1 导师 Agent

- `growth1`：成长计划生成
- `growth2`：学习评估

### 6.2 陪练 Agent

- `practice1`：实战对练
- `practice2`：实战评分
- `practice3`：实战能力更新
- `practice_mentor`：实战导师金句
- `practice_turn_feedback`：实战逐轮反馈

### 6.3 考官 Agent

- `wf11`：动态考核对话
- `wf13`：标准试卷生成
- `wf14`：标准试卷评阅
- `wf15`：阶段晋级解锁

### 6.4 客服 / 在岗助手 Agent

- `assistant1`：在岗助手主回复
- `assistant2`：在岗助手后台沉淀
- `assistant_chat`：在岗助手对话模式
- `qa1`：知识问答
- `qa_chat`：知识问答对话模式

### 6.5 分析师 Agent

- `dashboard`：风险看板
- `query1`：一句话查询解析
- `query2`：一句话查询总结

### 6.6 自我进化 Agent

- `evo_semantic`：语义记忆抽取
- `evo_reflective`：反思经验生成
- `evo_procedural`：技能规则综合

### 6.7 入职引导

- `onboarding`：新员工首登引导与起步任务

## 7. 知识库内容结构

系统知识库主要分为以下几类：

- 系统说明
- 产品知识
- 销售话术
- 异议处理
- 陪练场景
- 考核成长
- 经营看板
- 合规红线

这些内容分别服务于在岗支持、陪练训练、考试中心、成长计划和经营分析。

## 8. 典型业务闭环

1. 新员工登录后进入入职引导与成长计划。
2. 先通过理论学习和知识问答完成基础输入。
3. 再进入智能陪练完成场景化训练和逐轮反馈。
4. 通过考试中心和错题本验证掌握程度。
5. 结合成长之旅和训练周期持续更新能力画像。
6. 店长通过风险看板和一句话查询查看门店经营状态。
7. 系统把真实反馈沉淀到 EVO 记忆中，持续优化规则和体验。

## 9. 结语

Agent_O 的核心价值，不在于单点问答，而在于把“知识库 + 智能体 + 训练 + 考核 + 经营分析 + 治理”做成一个闭环系统。它既能服务一线顾客接待，也能服务新人培养、门店管理和系统演示。

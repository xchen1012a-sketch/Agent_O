# Agent_O UI 设计文档

## 1. 设计目标

Agent_O 的 UI 目标是专业、克制、清晰、可扫描，适合门店日常使用。界面重点不是炫技，而是让员工在高频操作中快速找到入口、看懂状态、完成任务。

## 2. 设计原则

- 以工作台为主，不做营销型首页。
- 信息层级清楚，主任务优先。
- 角色视图明显，不混淆管理员与一线员工。
- 表单、列表、看板、对话、结果页各有明确结构。
- 移动端和桌面端都能顺手使用。

## 3. 整体视觉

- 主体采用浅色工作台风格。
- 色彩以中性灰、蓝色强调、少量功能色为主。
- 圆角克制，卡片不夸张，避免浮夸装饰。
- 字体偏系统化、工具化，强调可读性。
- 以留白、分组和层级来组织信息。

## 4. 页面结构

### 4.1 登录页

- 居中登录卡片。
- 品牌标识在首屏明显展示。
- 用户名、密码、登录按钮清晰。
- 失败提示直接可见。

### 4.2 工作台

- 左侧为分组导航。
- 右侧为主内容区。
- 底部或侧边提供当前用户与账号设置入口。
- 页面可在移动端折叠为抽屉式导航。

### 4.3 内容页类型

- 列表页
- 详情页
- 对话页
- 表单页
- 看板页
- 结果页
- 弹窗与抽屉

## 5. 导航设计

导航按业务分组：

- 学习训练
- 考核复盘
- 成长规划
- 业务助手
- 组织管理
- 培训运营
- 系统治理

每组内的菜单项要短、明确、常用，避免一层塞太多入口。

## 6. 关键模块 UI 规范

### 6.1 理论学习

- 文档列表优先。
- 支持发布状态、分类和搜索。
- 阅读区突出正文，辅助信息放次级区域。

### 6.2 在岗助手 / 知识问答

- 采用对话式布局。
- 左右气泡区分用户与系统。
- 重要建议用结构化块展示。
- 支持语音与反馈卡片。

### 6.3 智能陪练

- 场景卡先于对话。
- 对话区保持连续感。
- 逐轮反馈要固定位置显示，方便用户边练边看。
- 评分、建议、下次动作要明显分层。

### 6.4 考试中心

- 题目、答题区、进度、提交按钮分区明确。
- 阶段结果页突出分数、是否通过、薄弱项和建议。
- 题目列表与答题记录可回看。

### 6.5 成长计划

- 使用时间线、阶段卡片或进度视图。
- 当前阶段、下一任务、已完成项目要清楚。
- 能力变化尽量可视化。

### 6.6 经营看板

- KPI 数字大、层级高。
- 趋势图与风险提示放在首屏。
- 支持表格、图表、时间范围切换。

### 6.7 人员与门店管理

- 以表格和详情抽屉为主。
- 适合批量查看、编辑和筛选。
- 风险操作需要明确二次确认。

### 6.8 系统治理

- 设置类页面保持清晰、简短、少噪音。
- 日志、审计、健康状态要高密度但可扫描。

## 7. 交互规范

- 主操作按钮使用高对比度强调色。
- 危险操作必须二次确认。
- 表单输入要即时校验。
- 空状态要告诉用户下一步该做什么。
- 加载态、失败态、成功态都要明确。

## 8. 响应式规则

- 手机端优先保证导航可用和内容可读。
- 平板端适合列表 + 详情双栏。
- 桌面端适合完整工作台与看板展示。
- 复杂表格在小屏上应转成卡片或折叠信息。

## 9. 组件建议

- 顶部信息条
- 分组侧边栏
- 状态标签
- 指标卡
- 时间线
- 对话气泡
- 结果评分卡
- 弹窗表单
- 详情抽屉
- 看板图表区

## 10. 文案风格

- 简洁、业务化、少解释性废话。
- 面向员工的文案偏指令和结果导向。
- 面向管理者的文案偏判断和行动建议。
- 避免夸张、营销化和口号化表达。

## 11. 视觉一致性

- 全站统一字号、间距、圆角和按钮层级。
- 同类页面保持相近结构，降低学习成本。
- 不使用过度装饰背景，不做大面积花哨渐变。

## 12. 典型页面信息层级

1. 页面标题
2. 当前状态
3. 核心动作
4. 主要内容
5. 辅助说明
6. 次级操作

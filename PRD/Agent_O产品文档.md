# Agent_O 产品文档

## 1. 产品概述

Agent_O 是一套面向珠宝门店的智能培训与经营辅助系统。产品目标是把门店知识、训练流程、考试评估、经营分析和治理能力整合到一个统一工作台中，帮助门店更快培养新人、更稳定输出话术、更清楚地看到经营风险。

## 2. 产品目标

- 缩短新人上岗周期。
- 统一销售话术和服务标准。
- 让陪练、考试、复盘和成长计划形成闭环。
- 把经营数据转成可执行建议。
- 让门店知识可沉淀、可检索、可复用。

## 3. 产品定位

- 面向珠宝门店内部员工，不是面向消费者的公开营销产品。
- 以培训、辅助、评估、复盘、分析为主。
- 核心不是单轮问答，而是“知识库 + 工作流 + 角色权限 + 任务闭环”。

## 4. 用户角色

- 管理员：配置系统、人员、门店、知识库、日志和治理。
- 店长：看经营、看风险、派任务、看团队成长。
- 资深顾问：做带教、陪练、答疑、复盘。
- 导购：学习、练习、考试、成长。

## 5. 核心使用场景

### 5.1 在岗支持

员工在真实接待中快速查产品、查话术、查异议处理和合规边界。

### 5.2 智能陪练

员工与模拟顾客对练，系统逐轮反馈并打分，帮助提升接待、挖需、推荐和成交能力。

### 5.3 考试评估

通过动态考核、标准试卷和阶段晋级检查员工是否达到上岗要求。

### 5.4 成长管理

根据学习与训练结果自动生成成长计划、学习任务和能力更新建议。

### 5.5 经营辅助

店长使用风险看板和一句话查询查看门店经营状态、库存问题和复购跟进。

## 7. 产品流程

1. 用户登录并进入对应角色工作台。
2. 新人先学理论，再进入陪练。
3. 陪练结果进入考试和复盘。
4. 考试与训练结果回流成长计划。
5. 店长通过看板和查询查看门店状态。
6. 真实对话和训练反馈进入记忆与进化机制。

## 8. 产品价值

- 对新人：更快上手。
- 对店长：更容易管理和观察团队。
- 对资深顾问：更容易带教和复盘。
- 对门店：知识沉淀更系统，训练更可控。

## 9. 产品边界

- 不替代专业鉴定。
- 不替代法律和人事裁决。
- 不承诺直接提升销售额。
- 不输出敏感配置和隐私数据。

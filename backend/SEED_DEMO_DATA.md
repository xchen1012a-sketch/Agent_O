# 演示数据导入与删除

脚本位置：`backend/seed_demo_data.py`

## 运行目录

推荐先进入 `backend` 目录：

```powershell
cd backend
```

## 命令说明

### 导入演示数据（默认）

先删除旧的 demo 数据，再重建一套新的完整演示数据：

```powershell
python seed_demo_data.py
```

### 删除演示数据

只删除这个脚本生成的 demo 数据：

```powershell
python seed_demo_data.py --delete-demo
```

### 重置演示数据

强制按”删旧 + 重建”的语义执行（与默认行为等价，语义更明确）：

```powershell
python seed_demo_data.py --reset-demo
```

### 指定数据库路径

```powershell
python seed_demo_data.py --db-path /path/to/your.db
```

## 行为说明

**导入时会：**
- 保留现有 `admin` 账号，不修改其密码
- 删除上一次脚本生成的全部 demo 数据
- 重新插入一套新的完整演示数据

**删除时不会影响：**
- 现有 `admin` 账号及密码
- 非脚本生成的其他业务数据

## 训练周期结构

演示数据中的训练周期已按系统真实结构生成：

- 共 2 个阶段，每阶段 7 天，总节奏 14 天
- stage-2 用户会同时保留已完成的一阶段 cycle 和当前阶段 cycle，共 30 个 cycle（19 用户中 11 个在 stage-1，8 个在 stage-2）

- 11 个用户仅有 stage-1 cycle（其中 1 个 voided），8 个用户有 stage-1 + stage-2 两个 cycle

- 统一标记：`demo_seed_v1`（存储在各记录的 source / payload 字段）

- 用户名列表：删除时精确匹配 19 个演示用户名
